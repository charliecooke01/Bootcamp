# The Interactive TODO List

## An interactive TODO list to display the use of DOM manipulation in JavaScript.

## User Story

As a user, I want to be able to manage my tasks using a simple web-based TODO list. I should be able to add new tasks, delete tasks, and, for bonus points, edit existing tasks and save the changes. The application should give me feedback if I try to add invalid tasks.

### Original requirements for the project:

- Users should be able to **add new tasks** to the list.
- Tasks should be displayed dynamically on the web page.
- Ensure that only **valid tasks** (non-empty or sensible values) are allowed to be added.
- Users should be able to **delete tasks** from the list.

### Instruction for use:

- Enter a task name into the input field and press the 'Create' button to generate a new task in the 'Active Tasks' container.
- Task name cannot be empty and cannot be a duplicate of another task name.
- Once created a task name can be edited by pressing the 'Edit Task' button.
- Input a new name into the box and press the 'Save Task' Button
- To delete a task press the 'Delete Task' button


### HTML

A simple html page to display a single container. The html includes:

- Page Title
- Create new task div includes an input field for the task name and a Create button.
- The task list div to be filled with new div content generated by the Javascript

### CSS

CSS to cover styling for the HTML and task list.

- Uses general styling for body and containers with color, spacing and font etc.
- Box styling for content and widget.
- Button styling.
- Input box styling.

### Javascript

JavaScript to handle DOM maniuplation by adding and removing new tasks. JavaScript includes:

- Get elements from HTML for Create task and add event listner.
- Function to create a new task:
   - Create task name (var taskValue)
   - Check if task name is valid
   - Create new html div (newItem) using 'taskValue' as ID names
      - paragraph
      - edit button
      - delete button
   - Create array (activeTasks)
   - Add 'newItem' to 'activeTasks' array
   - Add 'newItem' div to the html
   - Clear input box
- Function to remove current element if delete button is pressed
- Function to edit task
   - Select parent div of current paragraph
   - If to check if currently in editable state
   - If editable:
      - Turn off editable state
      - Change button text to 'Edit Text'
      - Update task name paragraph
      - Create a new task value
      - Validate task name
   - Else:
      - Turn on editable state
      - Highlight input box
      - Change button text to 'Save Text'
